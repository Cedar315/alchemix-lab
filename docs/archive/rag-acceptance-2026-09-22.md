> 历史记录：保留当时的设计、结果及限制，不代表当前实现。当前版本见 [文档导航](../README.md)。

本轮完成26个拟真场景、31轮对话的基线验收，并按失败原因修复路由、上下文、检索及生成约束。问题由项目场景编写，不是采集的生产用户日志。此问题集已用于调试，不能再宣称为独立测试集。

## 范围与复现

```bash
npm run eval:agent:acceptance
# 按场景复测，多轮场景会从第一轮开始
npm run eval:agent:acceptance -- A15 A24
```

问题与期望保存在 [companion-acceptance.ts](../../scripts/fixtures/companion-acceptance.ts)，执行器为 [evaluate-acceptance.ts](../../scripts/evaluate-acceptance.ts)。场景涵盖气泡摇和、重复用冰、薄荷、蜂蜜、双重过滤、干摇、酒精判断、经典配方、精确替代限制、陌生品牌、缺冰、材料替换、多轮故障、话题切换、取消、功能导航与混合请求。

执行器调用真实 `runCompanion → searchAndCollect → retrieve/generate/webEvidence` 链路，沿用45秒单轮截止时间。上一轮的 pending 与实际回答传给下一轮。记录原始输入、生成的检索问题、命中文档全文及分数、生成候选与证据核对、最终回答、失败类别和耗时。

本地数据库只读检查确认存在50条种子向量，datasetVersion 为 `c1ea3f6d1051b5c5444f8dc3a8144271d3906f5e027e0d0021371e8a5ae3d622`；真实检索验证了其与当前配置可配合使用。本轮没有重建索引或修改正式知识。测试问题的 collect 使用空实现，避免把人工测试问题写进知识审核队列。

这不是HTTP或浏览器端到端验收，不覆盖登录、用户额度、页面按钮执行或真实候选写库。程序断言不能代替语义忠实性审查，报告中的 humanReview 保持待审核。

## 找到的问题与修复

| 失败类型 | 真实运行证据 | 本轮修改 |
| --- | --- | --- |
| 路由遗漏任务 | A24、A25只给配方结果，未处理附带知识问题 | 混合请求交任务规划；保留明确附加知识问题，缺失时从原话恢复 |
| 库存污染 | 推荐与苏打水知识混合时，把苏打水写成已有材料 | 库存提取限定于声明材料的主请求 |
| 问题被扩写 | A07询问能否凭口感判断酒精量，被扩成具体酒款酒精数值 | 新的独立知识问题保留原文；补全指代不得增加任务 |
| 多轮事实覆盖 | A15完整用料被后续操作句中的部分材料覆盖 | 回答操作问题时保留已确认材料，明确纠正才更新 |
| 固定回答误用 | A17蜂蜜混不开触发乳饮分层固定说明 | 实际故障走材料相关检索，固定技法说明不接管故障 |
| 别名召回不足 | “分层了……用了牛奶”不能命中连续别名“牛奶分层” | 增加分散别名弱匹配，仍需满足原语义阈值 |
| 适用范围混淆 | A15混入了面向刻意分层配方的 layer-failure | 确认乳饮意外分层时排除该条；明确做分层酒时保留。仅依据用户实际材料，不依据页面默认材料 |
| 有引用但论断越界 | A13借青柠/黄柠檬条目解释柠檬茶质地；A16补出改变混合顺序或植物奶补救 | 生成后独立核对每条论断与引用正文/scope，不支持或不适用则拒绝，继续原有证据不足处理 |
| 因果限定词丢失及额外诊断 | A16曾被模型核对放行，但答案遗漏“可能”或增加混合顺序无关等断言 | 对引用只支持可能机制的因果表述，程序仅保留来源机制原句与完整scope；明确肯定诊断则拒绝。自动验收增加不确定性检查 |
| 协议错误未进入修复 | A10工具参数不合schema；A25工具调用数量不符 | 工具解码与决策schema共用最多两次规划尝试；网络错误不自动重试 |
| 核对输出截断 | 定向复测出现“证据核对未完成” | 生成和核对输出上限均为1400，仍保留20秒单次请求与45秒总截止；不展示未完成核对的答案 |
| 资料不足仍索要已知信息 | 已确认配方、材料和操作后，失败文案仍让用户重新补充 | 使用明确的证据不足文案；精确比例单独说明不能确定用量 |

生成模型只处理当前知识 question，不因为上下文里同时有推荐或导航请求就把知识部分判为无法完成。原因有依据而补救未知时，可以解释已支持的可能原因并明确补救依据不足。

最终离线回归161项通过，`npm run check` 执行类型检查和生产构建通过。后续修改采用定向真实复测，没有把不同代码阶段的通过记录拼成一次全量通过率。事实审查仅对照本次返回的知识正文与scope，未重新核验全部外部来源网页；仍需独立样本和人工专业审查。

## 仍未解决的知识覆盖

- **A12：啤酒柠檬茶缺冰的影响与具体处理。** 现有种子与本次可信搜索材料没有充分支持这个场景，助手说明资料不足。需要补充可核实的温度、稀释、气泡饮品条件资料，不能从其他酒“出杯不带冰”推出这杯制作时无需冰。
- **A13：柠檬茶替换为柠檬汁的风味与质地。** 现有“青柠汁与黄柠檬汁”条目不支持这个比较；实验室入口及正确材料迁移仍保留，知识回答不补编。需要覆盖实际饮料成分、甜度及品牌差异的资料。

不为了让自动通过率变高而把这些场景改成必然通过，也不自动把搜索摘要发布成正式知识。模型核对只能降低越界风险，不能证明所有通过的回答都正确。真实服务仍有随机性，本轮定向复测不是稳定性或高并发测试。
