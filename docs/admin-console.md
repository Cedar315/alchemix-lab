# AI 产品管理后台

核对日期：2026-10-14。当前助手架构见[架构设计](architecture.md)，部署配置见[操作手册](backend-operations.md)。

入口 `/admin`。所有页面与 API 复用 `requireAdmin`：可信 `app_metadata.role=admin` 或 `ADMIN_EMAILS`。普通用户无法访问。前端不提供权限设置和密钥管理。

## 页面和来源

- 总览：用户价值、采集覆盖、行为趋势、异常和待办。
- 用户：认证表注册量、服务端行为活跃/回访、首次观测 D1/D7 留存、制作记录、来源和页面使用。
- Agent：意图与执行状态、任务反馈、工具摘要、分页任务记录、脱敏会话侧栏及案例状态。
- RAG：涉及知识的请求、证据不足、召回证据；连接原知识审核和索引维护。
- 测试：Agent/RAG/仅检索单条与选定案例串行测试、结果持久化、人工评价、同案例同模式运行并排比较。测试不收集正式知识候选。批量在浏览器串行调度，关闭页面会停止后续请求；不自动重试。
- 运行：模型/版本、耗时、异常、用量覆盖、操作审计与清理。暂未完整采集跨服务 token/费用，不用局部用量伪造总费用。
- 内容：数据库配料、酒单查询和详情，只读。

## 口径

全部时间使用 UTC。默认滚动 7 天；今天为 UTC 当日至现在；自定义含结束日，最多366天。上期为等长区间；采集不完整时不显示变化。数据从部署后新增采集开始，不回填历史。

- 注册量来自 `auth.users`，按可信角色、测试标记及邮箱配置分开。
- 行为来自 `pm_events`；活跃为有事件的去重登录用户；匿名访客按浏览器标识计数，不等于自然人。
- `pm_tasks` 以用户+页面任务 ID 唯一归组，可能含多种意图，不宣称语义级独立任务。反馈更新一个任务，不重复计数；新请求会清空旧反馈。解决率分母仅已反馈任务，同时显示覆盖率。
- `pm_turns` 是请求粒度。返回 answered/handoff 等不代表用户问题已解决或操作已执行。无引用/证据不足与技术错误分开。
- `making_started` 为用户显式点击“我准备开始制作”。`drink_recorded` 仅服务端创建酒记成功后写入，客户端不能直接发送此保留事件。制作由用户自报，记录杯数非客观验证。
- AI 后制作仅为同用户、同期间任务后提交记录的时间关联，不代表因果归因或同一杯。
- D1/D7 按首次观测自然日分组，在对应日期观察回访；未成熟为 null。
- 来源为外部 referrer 的域名或 direct_or_unknown，不收集完整查询串。
- 内部身份从服务器可信 app_metadata、ADMIN_EMAILS、TEST_EMAILS 判断。分类为事件发生时快照；历史不因后续权限改变而自动重新分类。

## 留存与隐私

`pm_details` 普通详情30天到期即在读取时隐藏，Vercel每天03:15 UTC物理清理；已标记案例除外，取消标记后恢复期限。日清理存在最长约24小时物理删除延迟。`CRON_SECRET` 服务端加密配置必需。若数据库预装pg_cron，迁移亦注册同样日任务；当前数据库没有该扩展，使用Vercel任务。

历史元数据用于汇总，不保存原始提问；详细内容按需读取，同一任务最多100轮。自动遮盖常见邮箱、电话、URL凭据和密钥，禁止保存内部思考字段；自动脱敏不保证识别全部个人信息。测试输入与人工标记案例另行留存。隐私页面已说明采集和用途。

操作审计记录管理员ID、动作、对象和时间。知识与索引操作的 attempt 前缀表示尝试，不保证操作成功。测试记录保留运行状态，若服务器硬终止，running 表示未确认完成而非通过。

## 验证和运维

- `npm run test:admin`：指标边界、时间窗口、敏感文本、内部身份。
- `npm run test:admin:live`：需本地服务3003、隔离Chrome CDP9223，以及本地Supabase管理凭据。临时账号在finally中清理；验证鉴权、反馈归属/失效、保留规则、真实查询、规则导航测试和浏览器桌面/手机。截图位于 `artifacts/admin-console`，不是业务数据样例。
- `npm run check`：类型与生产构建。
- 新迁移 `20260922120000_product_console` 只新增表、索引、权限与清理函数。所有新表RLS开启，不向anon/authenticated授权；应用服务端访问。

尚未覆盖：完整成本归集、真实同配方制作归因、自动答案正确率、部署前历史的可靠用户行为。必须保留明确缺失状态，不能用模拟数值补齐。

## Agent 测试入口

打开 `/admin/evaluations`，选择“Agent 完整流程（当前新版）”，输入问题及可选页面背景，点击“运行单条”或运行选定案例。此入口复用用户端 `startAgent` 和 `agentUIStream`，执行当前新版模型、提示词、工具与实验室动作来源校验；等待完整运行后展示结果，不逐字播放。

结果保存回答、校验后的实验室动作、工具输入/输出、用量及耗时，可继续人工评价。测试不会写入正式用户指标或知识候选。历史模式 `agent-next` 显示为“Agent 当前新版”，原 `agent` 显示为“Agent 旧版”，两者不会作为同一模式比较。RAG 和仅检索模式不变。页面当前仍为单轮/独立案例测试，不提供连续对话操作。

测试结果默认直接展示答案正文；工具调用和原始 JSON 折叠在“查看详细记录”中。历史查看及版本对比同样优先展示正文，完整测试数据和人工评价仍照常保存。此调整只改变展示，不改变模型运行或等待完整结果的方式。

测试答案、历史列表和版本对比均显示响应时长（秒，保留两位小数）。新测试统一使用服务端请求开始到结果准备保存的同一计时值返回并持久化，包含鉴权、初始化和工具调用，不含最终保存及浏览器网络传输时间；不是首字时延。运行中显示“运行中”。

测试结果在答案正文前展示 `get_recipe` / `find_recipes` 返回的酒单卡片，并保留候选的待准备材料。按酒库中的真实 ID 解析站内链接，在新标签页打开，避免离开未保存评价。历史详情和版本对比共用此展示；没有对应工具结果的历史记录不会凭回答文字生成链接。
