## 状态口径

“当前实现”指本地工作区代码可观察的行为，不等于生产已部署；“已确认待实现”指用户认可的产品要求；“待验证”指需要数据、人工或真实环境验证。历史测试只证明当时版本和样本。

| 能力 | 当前实现 | 后续验证／限制 |
| --- | --- | --- |
| 入口 | 三处悬浮入口、手机容器内抽屉（含桌面预览）；首页不再主推问答 | 真实移动设备键盘和拖动体验需人工验收 |
| 选酒求助 | 复用共享目录与首页排序，最多三杯，具体详情链接 | 仅返回材料齐全且有可核对配方的候选，不保证库存数量足够 |
| 导航 | 受控同页定位、真实链接、材料预填及覆盖确认 | 无有效能力不生成入口 |
| 上下文 | 自动背景、任务版本、跨杯隔离、同杯临时对话 | 只保留当前杯最多24条消息；发送最近12条；换杯、离页或刷新后清空 |
| 知识问答 | pgvector、引用校验、当前缺料／制作场景接入 | 真实小样本不等于全部答案已人工审查 |
| 运维 | 登录、共享配额、v2日志与独立评估脚本 | 完整业务事件、全链路成本统计和关闭入口开关尚未完成 |

## 文档结构与维护约定

产品文档采用“功能目标—用户场景—处理策略—展示内容—异常规则—验收标准”的组织方式。参考实习文档的写法，不继承其角色、多模态或主动开场功能。

| 内容 | 唯一详细定义位置 | 其他文档的使用方式 |
| --- | --- | --- |
| 产品目标、范围、需求编号 | PRD | 概述并链接，不另定范围 |
| 意图与工具选择、候选条件 | Agent 方案 | 引用规则，不另造意图枚举 |
| 抽屉、跳转、任务生命周期 | 交互规范 | 引用操作结果与状态 |
| 动态模板与固定话术 | AI 回复规范 | 链接模板，不复制另一套固定文案 |
| 知识维护与检索策略 | RAG 文档 | 引用依据和状态口径 |
| 当前 API、数据、命令 | 服务／数据设计、操作手册及源码 | 目标设计与现状分开 |
| 测试步骤、指标和历史证据 | 验证文档 | 按用例 ID 关联需求 |

从 PRD 阅读产品全貌，再按链接进入专项规范。修改规则时先更新其详细定义，再同步概要、案例与验收；保留两张原有 Mermaid 流程图，不追加互相矛盾的“最新说明”。
